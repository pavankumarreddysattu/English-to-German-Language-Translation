# English to German Neural Machine Translation

A web-based Neural Machine Translation (NMT) application that translates English text into German using a pre-trained Hugging Face Transformer model. The application provides fast, accurate, and context-aware translations through an interactive Gradio interface.

## 🚀 Features

- English to German text translation
- Pre-trained Hugging Face Transformer model
- Real-time translation
- Interactive Gradio web interface
- Simple and user-friendly design

## 🛠️ Technologies Used

- Python
- Hugging Face Transformers
- PyTorch
- Gradio

## 📸 Demo

Enter English text and click **Translate** to receive the German translation instantly.

Example:

**Input**
```
Hello, how are you?
```

**Output**
```
Hallo, wie geht es dir?
```
